# Personal Portfolio Website

Welcome to the source code for my personal portfolio website! This project was built to showcase my experience, projects, and skills in a modern, interactive, and visually engaging way.

## 🚀 Tech Stack & Tools

This website was developed using a modern web development stack, prioritizing performance, responsiveness, and rich user interactions.

### Core Technologies
- **React (v19)**: Component-based UI design for a modular and maintainable codebase.
- **Vite**: Next-generation frontend tooling for an ultra-fast development server and optimized production builds.
- **Tailwind CSS (v4)**: Utility-first CSS framework for rapid, responsive UI styling and sleek design patterns.

### Interactive & Visual Libraries
- **Framer Motion**: A powerful animation library for seamless page transitions, scroll animations, and interactive components.
- **OGL**: A lightweight WebGL library used to render stunning 3D visual effects (such as the Liquid Ether, Aurora, and Galaxy backgrounds) for a premium, dynamic feel.
- **Lucide React**: Clean and consistent SVG iconography used throughout the interface.

### Deployment & Tooling
- **GitHub Pages**: Automated deployment of the production build directly from the repository using the `gh-pages` package.
- **ESLint**: Enforces code quality and consistency across the project.

## 📁 Project Structure

- `src/components/`: Contains all the reusable React components handling different sections of the site (`Hero`, `About`, `Experience`, `Projects`, `Connect`) as well as advanced WebGL backgrounds.
- `public/`: Hosts static assets including resumes and images.

## 🛠️ Running Locally

To explore the code or run this project on your local machine, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/alek3000/alek3000.github.io.git
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start the development server**
   ```bash
   npm run dev
   ```
